## 🚀 Featured AI/ML Work

### 🛡️ ShieldAI — Real-Time ML Content Moderation Platform
> Multi-stage ML pipeline moderating high message volume with a sub-100ms fast path

- **Two-stage ML cascade:** a DistilBERT classifier handles the fast path (<50ms), with an async LLM worker doing deep analysis on borderline cases and flagging classifier/LLM disagreement
- **Active learning loop:** human reviewer decisions feed back in as labeled training data, prioritized by where the ML model and LLM disagreed
- Kafka-driven async workers for text/image/LLM inference, autoscaled on Kubernetes by queue depth
- PII redaction before any content reaches an external LLM API

**Stack:** `HuggingFace Transformers` · `FastAPI` · `Kafka` · `PostgreSQL` · `Redis` · `Docker/K8s` · `LangChain`

[![Repo](https://img.shields.io/badge/View_Repository-24292e?style=for-the-badge&logo=github&logoColor=white)](https://github.com/VarunMA-23/Real-Time-Content-Moderation-Abuse-Detection-Platform)

### 🧠 Persistent Context Engine (PCE)
> Probabilistic causal reasoning over evolving system topology

- Built a **Topological-Invariant DAG** so causal reasoning survives infrastructure churn (renamed services, shifting dependencies)
- **Bayesian confidence scoring** with entropy-based damping to stop noisy nodes from dominating the causal story
- Rolling anomaly detection via **Welford's online algorithm**, fuzzy behavioral fingerprinting via Levenshtein distance
- Benchmarked: **0.92 Incident Recall@5**, **0.88 Causal Accuracy**, 1.8k events/sec ingestion

**Stack:** `Python` · `Probabilistic Graphs` · `Bayesian Inference` · `Docker`

[![Repo](https://img.shields.io/badge/View_Repository-24292e?style=for-the-badge&logo=github&logoColor=white)](https://github.com/VarunMA-23/persistent-context)
